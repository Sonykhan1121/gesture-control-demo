# Offline tutorial media

These local samples are used only in the simulated YouTube practice interfaces.

- `flower.mp4`: MDN interactive-examples CC0 video, https://github.com/mdn/interactive-examples/tree/main/live-examples/media/cc0-videos
- `coffee.png`, `cat.png` (Chelsea), `rocket.jpg`: scikit-image v0.19.3 sample data, https://github.com/scikit-image/scikit-image/tree/v0.19.3/skimage/data

The app does not open or control a real social account from this tutorial.

`guide-*.webp`: generated hand cutouts with white landmarks, created with the built-in image generation tool from the reviewed demo hand images. Prompt: remove the room background, preserve hand pose/anatomy/white landmarks, and output transparent alpha. WebP copies are compressed for animation in the app.
