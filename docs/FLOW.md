# Demo flow

[Project guide](../README.md) · [UI gallery](UI_GALLERY.md)

Welcome → local Login, Create Account or Guest → Add Device → Manually →
Gesture Control → Set Position → Choose Hand → Hand tutorials → YouTube practice
→ Active Home.

Settings offers Face/Hand/Social mode, saved resting position, physical hand,
appearance, languages, tutorial replay, About and logout. A live face uses its
absolute camera position; its saved position is used before detection or after
face loss. The Face-mode preview keeps the actual camera aspect ratio.

Auto Search scans real nearby Bluetooth advertisements. Selecting a device
continues local setup; GATT connection and stand commands are not implemented.
