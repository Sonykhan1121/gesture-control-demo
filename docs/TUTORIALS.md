# Tutorials

[Project guide](../README.md) · [UI gallery](UI_GALLERY.md)

Hand: Fist, Move Right, Move Left, OK, Victory, Move Down, Move Up, Rock On,
Thumbs Down, Thumbs Up, Dorsal, Open Palm, Punch.

YouTube: Previous Video, Next Video, Scroll Up, Scroll Down, Play, Pause,
Volume Up, Volume Down. Point in the corresponding direction; Play/Pause use
Punch, and volume uses Thumbs Up/Down. These are offline player simulations.

Face: face presence, left/right, up/down, smile, talk.

Recognition uses real camera frames. Training enforces the selected physical
hand. Social practice accepts a correct hand anywhere in the camera frame and
preserves progress through brief shaking. Successful practice advances
through the shared lesson flow; Skip skips the current exercise.
