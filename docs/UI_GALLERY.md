# UI gallery

[Back to README](../README.md)

Portfolio demo app screens in **portrait and landscape**, rendered on 1 November 2026 from the production Flutter widgets at 402 × 874 and 874 × 402 logical pixels. Click any preview to view it at full size.

These are reproducible UI renders, not live-device acceptance screenshots. Local adapters supply sample account/device data, blank camera regions, and a still frame from the bundled sample video. No real credentials, provider accounts, camera photos or hardware are used. Android/iOS system bars, permission sheets and provider-owned Google/Facebook browser pages are outside this gallery.
